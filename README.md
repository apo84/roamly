#Trove - Your Serendipitous Travel Buddy

This is a project developed by Aidan O'Sullivan, Faatiha Kalam, Maggie Jens, and Ella Rodrigues

We are currently hosting on vercel at https://trove-kappa.vercel.app/

Developer Notes:

Change `.env.local` to `VITE_APP_URL=http://localhost:8080` and `VITE_API_URL=http://localhost:4000` when developing locally.

*On Vercel, set `VITE_APP_URL=https://trove-kappa.vercel.app` and `VITE_API_URL=<your-backend-base-url>` so OAuth and `/api/me` calls point at the right hosts.*
